🔧 ALTERNATIVE METHODS (If Needed)
════════════════════════════════════════════════════════════════════════════════

METHOD 2: django-extensions (Automated from Django)
───────────────────────────────────────────────────────────────────────────────
1. pip install django-extensions pydot
2. Add 'django_extensions' to INSTALLED_APPS in config/settings.py
3. python manage.py graph_models accounts planner notes resources quizzes ai_assistant dashboard -g -o erd.png

Pros: Automated, always current
Cons: Requires Graphviz, less customizable

METHOD 3: ERDAlchemy (From database)
───────────────────────────────────────────────────────────────────────────────
1. pip install eralchemy
2. eralchemy -i 'postgresql://user:pass@localhost/ai_study_hub' -o erd.png

Pros: Reads actual database
Cons: Shows internal Django tables too

METHOD 4: Manual (Draw.io, Lucidchart)
───────────────────────────────────────────────────────────────────────────────
Use ERD_TEXT_PREVIEW.txt as reference
Draw tables and relationships manually

Pros: Complete control
Cons: Time-consuming, manual updates needed
