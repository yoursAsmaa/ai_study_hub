PROBLEM:
"Invalid AI API key. Please check your configuration."

DIAGNOSIS COMPLETE:
✓ Code is configured correctly
✓ Provider: OpenAI (gpt-4o-mini)
✓ Environment variable: AI_API_KEY
✓ Security: API key is server-side only
✗ Your .env file needs to be configured with your OpenAI key

═══════════════════════════════════════════════════════════════════════════════
🔧 HOW TO FIX (3 STEPS)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Open Your .env File
────────────────────────────
Location: Project root (same folder as manage.py)
File: .env

STEP 2: Add Your OpenAI API Key
────────────────────────────────
Add this line (replace with your actual key):

AI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

IMPORTANT - Common Mistakes:
✗ AI_API_KEY="sk-proj-xxx"              (NO quotes)
✗ AI_API_KEY = sk-proj-xxx              (NO spaces around =)
✗ AI_API_KEY=sk-your-openai-api-key    (NO placeholder)
✓ AI_API_KEY=sk-proj-xxx                (CORRECT)

Get your key from: https://platform.openai.com/api-keys

STEP 3: Restart Django Server
──────────────────────────────
CRITICAL: You MUST restart after changing .env

1. Press Ctrl+C to stop the server
2. Run: python manage.py runserver
3. Test the AI chat again

═══════════════════════════════════════════════════════════════════════════════
🧪 RUN DIAGNOSTIC COMMAND
═══════════════════════════════════════════════════════════════════════════════

I created a safe diagnostic tool for you:

python manage.py check_ai_config

This command will:
✓ Check if .env file exists
✓ Check if AI_API_KEY is loaded
✓ Report key length (without showing the actual key)
✓ Detect common issues (whitespace, quotes, placeholder)
✓ Provide specific fix instructions

SECURITY: Your API key is NEVER printed or exposed.
